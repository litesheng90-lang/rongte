# 荣特电子产品网页

静态网页模板，适用于展示荣特电子的数据线产品、规格和联系方式。支持轮播海报、视频展示、核心优势介绍、分类产品卡片、定制流程图示与二维码信息。

## 本地预览

直接打开 `index.html` 即可在浏览器中查看页面效果。也可以使用任意静态服务器，例如：

```bash
npx serve .
```

## 文件结构

```
├── index.html        # 页面结构与文案，可根据需求自由修改
├── styles.css        # 页面样式，可调整配色、布局等
├── script.js         # 交互脚本，控制轮播、分类切换等效果
└── assets/
    ├── placeholder-product.svg  # 产品图片占位图，可替换为实际产品图片
    └── placeholder-qr.svg       # 二维码占位图，可替换为微信/1688 二维码
```

## 自定义说明

### 快速修改文字与链接
- 页面右上角新增“开启编辑模式”按钮，点击后带有 `虚线框` 的文字、按钮文案与联系方式都可以直接在浏览器中修改。
- 修改完成后再次点击按钮退出编辑模式，即可看到最终效果。需要永久保存时，将更新后的内容复制回 `index.html` 对应位置。
- 若需批量调整或新增段落，也可以直接在代码中搜索 `data-editable` 标记，替换其中的文字与链接。

### 顶部公司简介轮播
- 每个 `.hero-slide` 支持图片、视频或宣传海报文字。
- 若要新增幻灯片，复制一份 `.hero-slide` 结构，并更新图片或视频地址。
- `data-interval` 属性用于控制自动切换时长（毫秒）。
- `.hero-badges`、`.hero-actions` 可自定义卖点与按钮文案，以匹配企业定位。

### 核心优势区块
- 位于 `#advantages` 区域的 `.highlight-card` 用于展示产线、定制、品控等能力。
- 可调整 `span.highlight-icon` 的内容或替换为自己的 SVG 图标。

### 产品与规格
- 产品按照分类放置在 `category-panel` 中，可自由增删分类。
- 每个产品卡片 `.product-card` 内的图片列表支持 1~3 张图片。
- 图片数量超过 1 张时，会根据 `data-interval`（默认 5000ms）自动轮播，可悬停暂停。
- 规格参数在 `<ul>` 列表中编辑即可。

### 定制流程展示
- `#process` 区域使用有序列表呈现 5 个步骤，可按需要增删。
- 每个 `.process-step` 的标题与说明对应项目阶段，可替换为自身流程说明。
- `.process-cta` 中的按钮支持自定义为电话、微信或邮件链接。

### 底部联系方式
- 二维码图片与联系方式均可直接修改文本或替换图片。
- 微信、抖音、小红书图标已内置矢量图，可调整链接地址跳转至您的官方账号。

## SEO 建议
- 将 `<title>`、`meta` 描述和页面文字替换为与品牌相关的内容。
- 为图片添加更具体的 `alt` 描述，有助于搜索引擎收录。

## 部署
- 可直接部署至任意静态网站托管平台（如 GitHub Pages、Vercel、阿里云 OSS 等）。
